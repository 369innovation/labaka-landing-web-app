# Labaka Landing Web App

This repository contains the standalone landing webpage and public marketing / legal pages for **Labaka**.

## 🚀 Features & Pages
- **Home Page (`/`)**: High-converting, interactive landing page featuring animated stats, real-time discovery showcases, app features, testimonials, and mobile download modal.
- **Contact Us (`/contact`)**: Support form, subject routing, contact info, and FAQs.
- **Upgrade Page (`/upgrade`)**: Subscription plan comparison, feature matrices, and membership upgrade CTAs.
- **Static Pages (`/Labaka/*`)**:
  - `AboutUs`: Story and mission overview.
  - `PrivacyPolicy`: Comprehensive legal and privacy policy documentation.
  - `Faqs`: Direct support questions.
  - `terms-and-conditions`: Terms of service.

## 🛠️ Tech Stack
- **Framework**: React 18
- **Routing**: React Router DOM v6
- **UI Components & Styling**: Material UI (MUI v5) & Emotion
- **Notifications**: React Toastify

## 📦 Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm start
```
The application will launch on `http://localhost:3000`.

### Production Build
```bash
npm run build
```
Generates production-optimized bundle files inside the `build/` directory.
